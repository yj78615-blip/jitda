## 배운 것
- **웜 재측정이 진단 절대 첫 스텝.** 웜이어도 느리면 콜드 스타트 아님. 리전 · DB · 렌더링 병목 중 하나. 이번 오진의 뿌리 = 웜 baseline 을 진작 안 잰 것.
- **`X-Vercel-Id` 헤더 = 리전 진단의 확정 도구.** 형식 `<edge>::<function>::...`. 함수 리전이 DB 랑 다른 대륙이면 무조건 큰 축.
- **Vercel 기본 함수 리전 = `iad1`** (프로젝트 대시보드에서 안 바꿨다면). DB 가 아시아면 `vercel.json regions` 로 반드시 매칭.
- **커넥션 풀 설정이 완벽해도 리전이 나쁘면 소용없음.** pooler + pgbouncer + connection_limit=1 다 갖춰도 왕복 자체가 180ms 면 3 쿼리에 500ms + Prisma init.
- **외부 UI 안내는 검증된 것만.** 확신 없으면 사용자 캡처 요청. 규칙으로 저장했으니 다음 세션부터 적용.
